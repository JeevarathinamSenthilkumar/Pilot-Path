# Pilot Path — Chapter 1: Visual Learning Rebuild

Open `index.html` by double-clicking on Windows or macOS after extracting the ZIP. No web server required for included content. For iPhone, upload the folder contents to GitHub Pages and open the HTTPS address in Safari, then Add to Home Screen.

Includes 18 topic-focused lessons, 120 short teaching concepts, original embedded FAA illustrations (extracted individually, not page screenshots), subject-specific custom illustrations, local saved progress, optional brief lesson checks where appropriate, and a separate exam section.

## How the visuals work
Individual FAA figures appear where relevant to a specific concept. Custom teaching visuals appear only when an FAA figure does not teach the concept well. Many short concepts intentionally have no image. Tap an image to enlarge. Files are organized under `assets/images/faa` and `assets/images/custom`; consult `IMAGE-MAPPING.csv` for exactly what appears in each concept.

## Limitations
- Chapter 1 only (not the full 17 chapters).
- Compact concept explanations; still needs formal subject-matter review to assert complete mastery coverage.
- Questions are custom practice, not official FAA knowledge test questions.
- For actual flying, verify the latest FAA regulations and documents and work with a qualified flight instructor.
- Progress saves in this browser/device, with no account synchronization. A local file and the GitHub website have different browser storage origins.
