# Pilot Path — Chapter 3: Aircraft Construction

**Run on Windows:** Extract the ZIP and double-click `index.html` in Chrome. No internet connection or local server is needed for the bundled lessons, artwork, assessments, or progress.

**GitHub Pages / iPhone:** Upload the extracted **contents** to a repository root; enable GitHub Pages. Add the site to your iPhone Home Screen if desired.

This is a **standalone Chapter 3 site** so it does not overwrite completed Chapter 1 or Chapter 2. The site has 18 lessons and 101 concepts. App-authored comprehension checks are optional and remain separate from the exam.

All images in the lesson content are **cropped original diagrams and photos from FAA-H-8083-25C** Chapter 3; no decorative images have been added. Image usage is explained in `IMAGE-MAPPING.csv`. Text is educational paraphrase and practice examples, not FAA-approved training, and is not an operating instruction. Verify current regulations, procedures, and the aircraft POH/AFM.
