# Pilot Path — Chapter 4: Principles of Flight

Extract and double-click `index.html` to open in Chrome on Windows or Mac; lessons are embedded, no local server or network required.

For iPhone, upload the extracted folder contents to GitHub Pages.

Standalone Chapter 4 application; does not overwrite Chapters 1–3. Includes 13 lessons and 70 teaching concepts.

Figures cropped from the original FAA handbook and mapped to relevant explanations. Not intended as operational flight instruction. Use current FAA guidance and your aircraft POH/AFM for real flying.
